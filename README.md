# TimeShift: Xbox 360 Gamepad Mod (PC)

Мод переносит в PC-версию TimeShift (2007) управление геймпадом из версии для Xbox 360: раскладку,
иконки кнопок Xbox в подсказках и меню, вибрацию, настройки чувствительности, экран с картинкой
геймпада и пресетами раскладки.

Мод сделан как `dinput8.dll`: это прокси-библиотека, которая при запуске игры исправляет
`TimeShift.Exe` в памяти. Файл exe на диске не меняется, и в моде его нет.

---

## Что умеет мод

| Возможность | Подробности |
|---|---|
| Геймпад в игре | Любой XInput-контроллер (Xbox 360, Xbox One/Series и совместимые). В PC-версии код джойстика был, но не запускался: мод его включает. |
| Раскладка с Xbox 360 | Все действия назначены как на консоли (таблица ниже). |
| 4 пресета кнопок и 4 пресета стиков | `Common`, `Left-Handed`, `Swapped`, `Swapped Left-Handed` и т. д., как в `x360_config.ini` консольной версии. Переключаются в меню, игра их подхватывает сразу. |
| Иконки Xbox в подсказках | «Нажмите X, чтобы перезарядить» вместо «Нажмите R». Подсказки рисуются иконками из консольного шрифта. |
| Иконки на кнопках меню | `A ПРИНЯТЬ`, `B НАЗАД`, `Y ПО УМОЛЧАНИЮ`, `A ВЫБРАТЬ` в меню паузы и т. д. Показываются только при подключённом геймпаде. |
| Навигация по меню | Стик и крестовина двигают выделение, A выбирает, B и Start возвращают назад. Курсор мыши не мешает выбору. |
| Вибрация | Включается и выключается в меню (в оригинале был только ключ в `user.ini`). |
| Чувствительность | Отдельные настройки: обзор, движение, инверсия Y, мёртвая зона стиков. |
| Экран «Camera Settings» | Пункт `MOUSE CONTROLS` переименован в `CAMERA CONTROLS`. Внутри три страницы: **Камера** (настройки), **Кнопки геймпада** (картинка геймпада 360 с подписями) и **Стики** (картинка со стрелками). Пресет выбирается влево и вправо, подписи на картинке меняются. |
| Хроноконтроль | LB, LB+X, LB+Y, LB+B, как на консоли. В HUD включены текстуры кнопок Xbox для кругового меню способностей. |
| Языки | Новые строки переведены на все 9 языков игры; русский перевод сделан вручную. |

## Установка

**Что нужно:**
1. TimeShift (Steam или диск, патч 1.02).
2. **Исправленный exe «multi-core CPU fix» v1.2** из руководства Steam:
   <https://steamcommunity.com/sharedfiles/filedetails/?id=1869921614>.
   Без него игра всё равно вылетает на современных многоядерных процессорах, а мод рассчитан
   именно на этот exe. С другим exe мод покажет предупреждение, и игра запустится без мода.
3. Windows 10 или 11 (на Windows 7 и 8 нужен Universal C Runtime, KB2999226).

**Шаги:**
1. Сделайте копию `preload\paks\patch.s3darc` (например, `patch.s3darc.bak`).
2. Скачайте архив из раздела **Releases** и распакуйте его в папку игры
   (`...\steamapps\common\TimeShift\`) с заменой файлов. Появятся:
   - `bin\dinput8.dll`
   - `preload\paks\patch.s3darc`
3. Подключите геймпад и запустите игру обычным способом.

При первом запуске мод сам:
- добавит привязки геймпада в `controls.ini` (в `bin\` и в папке профиля `UserConfigs\<профиль>\`);
- добавит свои настройки в `user.ini` профиля.

Перед изменением он сохраняет копии `*.before_gamepad_mod`, один раз.

### Удаление
1. Удалите `bin\dinput8.dll`.
2. Верните старый `patch.s3darc` из копии.
3. Если нужно вернуть прежние клавиши, переименуйте `controls.ini.before_gamepad_mod` обратно в `controls.ini`.

## Настройки

В игре: **Options → CAMERA CONTROLS**.

| Пункт | Ключ `user.ini` | По умолчанию |
|---|---|---|
| Чувствительность геймпада | `LookSensitivity` | 100 |
| Инверсия по Y | `InvertLookY` | no |
| Вибрация | `Vibration` | yes |
| Мёртвая зона стиков, % | `DeadZone` | 22 |
| Чувствительность движения | `MoveSensitivity` | 100 |
| Пресет кнопок (1–4) | `GamepadButtons` | "1" |
| Пресет стиков (1–4) | `GamepadSticks` | "1" |

Изменения в `user.ini` подхватываются на лету, примерно раз в полсекунды.

## Как это работает

### Исправления exe (`asm/`, применяются из `dinput8.dll`)
Игра импортирует `dinput8.dll`, поэтому прокси загружается раньше, чем начинает работать `TimeShift.Exe`. Прокси сначала
сверяет все 32 участка (около 3 КБ) с ожидаемыми байтами. Если всё совпадает, он записывает код мода
в пустой хвост секции `.text` (`0xD10300–0xD11000`), а остальные вызовы передаёт системному `dinput8.dll`.

| Файл | Адрес | Что делает |
|---|---|---|
| `frame.s` | `0xD10600`, хук `0x785FE0` (кадр ввода) | Создаёт DirectInput-устройство геймпада и включает XInput, который в PC-сборке был отключён. Читает `user.ini` профиля (чувствительность, мёртвая зона, вибрация, пресеты). Убирает курсор, когда последним активным устройством был геймпад. |
| `remap.s` | `0xD10D00`, слот vtable `0xDB70B4` (опрос джойстика) | После опроса заполняет «виртуальные» кнопки `0x112+i` и оси `0x13C–0x147` по таблицам пресетов. Так 4×4 раскладки работают без перезаписи `controls.ini`. |
| `getname.s` | `0xD10400`, хук `0x786700` (имя клавиши) | Возвращает для кодов геймпада символы-иконки из шрифта (À = A, Á = B, Ä = X, È = Y, Æ = LB, Œ = RB, É = LT, Ñ = RT…), поэтому подсказки показывают кнопки Xbox. |
| `strkey.s` | `0xD10C50`, хук `0x691210` (поиск в таблице строк) | Кнопки меню ссылаются на ключи `UI_BTN_*_GP<буква>`, у которых есть вариант с иконкой. Без геймпада хук отбрасывает суффикс и показывает обычный текст. |
| `consts.s` | `0xD10300` | Константы. |
| — | `0x7BCD4C…0x7BCDE4` | Масштаб осей стиков берётся из глобальных переменных мода. |
| — | таблица меню `0xEC1E14…` | Добавлены альтернативы геймпада для LEFT, RIGHT, UP, DOWN, ENTER и ESC. |

Глобальные переменные мода лежат в свободном хвосте `.data`/bss (`0x10E0F00–0x10E1000`).

### Ресурсы (`patch.s3darc`, скрипты в `assets/scripts`)
Формат архивов Saber3D пришлось разобрать с нуля: 360 `.s3dpak` и PC `.s3darc`, индекс, пакет `ps` с UI-скриптами, текстуры.

- **Шрифты** `font_main*` и `font_regular*`: добавлены глифы кнопок Xbox из консольных шрифтов.
- **Текстуры** `gp_pad`, `gp_pad_spider` и `gp_pad_sticks1–4` (картинки геймпада из 360-версии с прозрачным
  фоном и стрелками стиков), `xbox_*_button` (иконки A, B, X, Y для HUD хроноконтроля). Все текстуры зарегистрированы в 40 списках пакетов.
- **UI**: новый фрейм `OptionsMouse` (камера и геймпад, SSL-скрипт пресетов). В HUD раскомментированы текстуры кнопок Xbox. В 353 кнопках меню с `XBoxShortCut` текст заменён на ключи `_GP<буква>`.
- **Строки**: ключи `UI_GP_*`, названия пресетов `UI_CTRL_buttons_N` и `UI_CTRL_thumb_N`, 49 вариантов кнопок с иконками, на 9 языках.

### Коды ввода PC-движка (для справки)
`0x00–0xFF` клавиатура (DIK), `0x100–0x107` кнопки мыши, `0x108–0x123` кнопки джойстика
(A `0x108`, B `0x109`, X `0x10A`, Y `0x10B`, LB `0x10C`, RB `0x10D`, Back `0x10E`, Start `0x10F`, LS `0x110`, RS `0x111`),
`0x12C–0x131` оси мыши, `0x132–0x153` оси джойстика (LT `0x136`, RT `0x137`, крестовина `0x142–0x145`).
Мод использует виртуальные кнопки `0x112+i` и виртуальные оси `0x13C–0x141`, `0x146–0x147`.

## Сборка

```sh
pip install ziglang          # MinGW-тулчейн для 32-битной Windows DLL
./build.sh                   # → dist/bin/dinput8.dll
```

Пересобрать таблицу исправлений после правки `asm/*.s` (нужны GNU binutils с i386):
```sh
python3 tools/build_exe_patch.py path/to/TimeShift.Exe [patched_for_debug.exe]   # → src/patches.h
./build.sh
```

Скрипты в `assets/scripts/` собирают `patch.s3darc` из оригинального `patch.s3darc` и ресурсов
360-версии. Это исследовательские скрипты, рабочие пути в них заданы переменной `S` в начале файла.
Оригинальные ресурсы игры в репозиторий не входят; готовый `patch.s3darc` лежит в Releases.

## Состояние и известные ограничения

- **Проверено в игре** (на exe с исправлениями): геймпад, вибрация, перезарядка на X, подсказки с иконками,
  навигация по меню, настройки камеры и геймпада, экран раскладки с пресетами.
- **Ещё не проверено:**
  - сама `dinput8.dll` (до неё исправления тестировались прямо в exe, код тот же);
  - иконки на кнопках меню после последнего исправления;
  - иконки в круговом меню хроноконтроля;
  - прозрачный фон картинки геймпада;
  - работа пресетов в самой игре.
- Видимый курсор мыши в меню не прячется, его просто игнорируют при выборе пунктов.
- Круговое меню хроноконтроля в PC-версии открывается двойным нажатием LB с удержанием.
- Мод поддерживает только exe «multi-core fix» v1.2. Оригинальный exe Steam зашифрован SteamStub,
  и адреса в нём другие.
- Геймпад определяется при запуске игры. Если подключить его позже, нужен перезапуск.
